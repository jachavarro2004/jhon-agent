## Remote operations

Local development does not authorize remote execution or file transfer.
Remote work needs the user's explicit authorization for the destination, the
operation, and the credential or session to use; when any part is missing,
ask and stay local, without probing the destination. Before any remote
access, push, `gh` write, publish, deploy, or a deletion that loses work or
data, read `~/.local/share/jhon/current/prose/contracts/asked-operations.md`.
