## Artifact Language

An artifact is anything produced for the task rather than said to the user:
code, identifiers, comments, strings, UI copy, tests, documentation, commit
messages, PR descriptions, specs, and memory entries.

- Artifacts are in English, whatever the conversation language.
- Extending a project that clearly uses another language, match the project.
- An artifact explicitly requested in Spanish uses neutral professional
  Spanish.
- No regional slang, dialect, or stylistic emphasis in any artifact.
- PR reviews and issue replies follow the language of their context, in a
  neutral register, unless the user says otherwise.
- A delegation prompt names a language only when the user stated one.
