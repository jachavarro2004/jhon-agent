Coding agents write fast. The question is what you can trust.
Jhon lets the agent run, and asks one thing of every change: evidence.
A test that failed first, then passed. Recorded, not claimed.
Only the tree that was tested is delivered.
Guards stop only what can't be undone: a destructive command, a write outside the project.
Everything else runs free, inside a sandbox.
Risky changes get the Prism review: four facets, a challenger, an arbiter.
Claude Code or pi. Your model. And an audit of every session.
