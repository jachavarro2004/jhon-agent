# tools/

Development tools for this repository; nothing here is installed.

| Path | What it is |
|---|---|
| `bench/` | The benchmarks (T39): the same tasks run with Claude Code clean, Claude Code with Jhon and pi with the Jhon shell, in a dedicated bench HOME; each task's hidden acceptance test decides success. `go run ./tools/bench prepare|login-check|run|report`; see `bench/README.md`. Runs spend the owner's Claude quota: `--dry-run` first, and `--budget-points` stops them. |
| `coverage/` | The rule coverage matrix: `go run ./tools/coverage [filter]`. For every validation rule it injects one real defect into each layer the rule covers, expects `jhon validate` to report it there, and restores the tree with `git restore`. It needs a clean, committed tree. `jhon test` runs it last. |
| `release/repro.sh` | The reproducibility check of a release (T52): `tools/release/repro.sh <jhon> <version> <reference-dir>`, run in the checkout the reference was packed from, packs the same commit again (without re-running the Go tests) and compares each `jhon-<version>-linux-*` artifact with the reference byte for byte; any difference fails. The release workflow runs it after its pack, before signing. |
| `git-hooks/pre-commit` | Refuses a commit whose tree does not build or does not validate. Install it once per clone: `git config core.hooksPath tools/git-hooks`; `jhon doctor` reports whether it is active. |
| `git-hooks/pre-push` | When a push updates `main`, refuses it unless go vet and staticcheck pass on the whole module and the conformance suite `go test -p 4 ./test/...` passes; when the push changes the guards, the sh reader, the hooks, project, settings, the corpus or guarddiff since the last release tag, it also runs `tools/guarddiff` against that release's binary (built once per tag into `$XDG_CACHE_HOME/jhon/guarddiff/<commit>/`) and refuses a changed verdict not on `tools/guarddiff/allow.tsv`; pushes of other branches run nothing. A sha that already passed them on this machine (a second remote, a re-push) is not checked again: it prints `pre-push: <sha> already passed; skipping`; the record is `.git/jhon/pre-push-passed`, keyed by the sha and a hash of the hook, and a failed run records nothing. Installed with the pre-commit hook (`core.hooksPath`). |
| `guarddiff/` | The guards' verdict differential (T128f): `go run ./tools/guarddiff --old <jhon> --new <jhon> --allow tools/guarddiff/allow.tsv`; see `guarddiff/README.md`. |
| `phasegate/` | The phase gate (T269): `go run ./tools/phasegate measure --label <phase> --jhon <jhon> …` records a build's speed in the owner's projects (read-only, one call at a time), its guard stops per 100 tool results in real use, its fixed texts' budgets, a suite's TMPDIR leftovers and the correctness results; `compare --base <label> --new <label>` fails on a regression past its tolerance; see `phasegate/README.md`. |
| `readme-media/` | The README's images made by code: the banner, the shell's and the engine's captures, the dashboard's page and the diagrams (`node --experimental-strip-types tools/readme-media/build.ts`); see `readme-media/README.md`. Jhon's videos are made with jhon-studio (github.com/jachavarro2004/jhon-studio), an opt-in integration. |
